# For-Climate-Anxiety-Manuscript-
# Data and code for "Climate anxiety among urban residents in Sylhet City, Bangladesh"

Supplementary data and analysis code for the manuscript submitted to Climatic Change.

- ESM_4.pdf    — measurement and robustness appendix
- ESM_5.ipynb  — annotated analysis notebook; reproduces every statistic and Table 2
- ESM_6.xlsx   — de-identified participant-level dataset

Run ESM_5.ipynb against ESM_6.xlsx to reproduce the reported results.
